# HDLBits helpers

These are **local stand-ins** for modules that [HDLBits](https://hdlbits.01xz.net/wiki/Problem_sets) already provides when you submit. They exist so you can compile hierarchical problems with Icarus Verilog on your machine.

Do not paste these files into the HDLBits editor (the site already has its own `mod_a`, `add16`, `bcd_fadd`, and so on).

| File | Used by |
|------|---------|
| `mod_a.v` | Modules (simple 2-input) |
| `mod_a_6port.v` | Connecting ports by position / by name |
| `my_dff.v` | Three modules |
| `my_dff8.v` | Modules and vectors |
| `add16.v` | Adder 1/2, carry-select, adder-subtractor |
| `bcd_fadd.v` | BCD adders |
| `count4.v` | Counter 1-12 |
| `bcdcount.v` | Counter 1000 |
| `parity.v` | Serial receiver with parity checking |
