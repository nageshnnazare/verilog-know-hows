# 039. Reduction: Even wider gates

**Section:** Verilog Language — More Verilog Features  
**HDLBits:** [Reduction: Even wider gates](https://hdlbits.01xz.net/wiki/Gates100)

## Problem

100-input AND, OR, and XOR of `in[99:0]`.

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`039_gates100.v`](./039_gates100.v).

```verilog
module top_module (
    input  [99:0] in,
    output        out_and,
    output        out_or,
    output        out_xor
);
    assign out_and = &in;
    assign out_or  = |in;
    assign out_xor = ^in;
endmodule
```
