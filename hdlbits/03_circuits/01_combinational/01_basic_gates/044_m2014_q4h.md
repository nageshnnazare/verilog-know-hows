# 044. Wire

**Section:** Circuits — Combinational Logic — Basic Gates  
**HDLBits:** [Wire](https://hdlbits.01xz.net/wiki/Exams/m2014_q4h)

## Problem

Connect output `out` directly to input `in`.

## Figures (from HDLBits)

Copied from the official HDLBits problem page for this tutorial.

![Figure 1](./044_m2014_q4h_fig1.png)

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`044_m2014_q4h.v`](./044_m2014_q4h.v).

```verilog
module top_module (
    input  in,
    output out
);
    assign out = in;
endmodule
```
