# 048. Two gates

**Section:** Circuits — Combinational Logic — Basic Gates  
**HDLBits:** [Two gates](https://hdlbits.01xz.net/wiki/Exams/m2014_q4g)

## Problem

The exam figure is an AND of in2 and in3, then XOR with in1:
  out = in1 ^ (in2 & in3)

## Figures (from HDLBits)

Copied from the official HDLBits problem page for this tutorial.

![Figure 1](./048_m2014_q4g_fig1.png)

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`048_m2014_q4g.v`](./048_m2014_q4g.v).

```verilog
module top_module (
    input  in1,
    input  in2,
    input  in3,
    output out
);
    assign out = (~(in1 ^ in2)) ^ in3;
endmodule
```
