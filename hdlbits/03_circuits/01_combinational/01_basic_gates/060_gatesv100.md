# 060. Even longer vectors

**Section:** Circuits — Combinational Logic — Basic Gates  
**HDLBits:** [Even longer vectors](https://hdlbits.01xz.net/wiki/Gatesv100)

## Problem

Same neighbour-AND / neighbour-OR / wrap-XOR as Gatesv, but 100 bits.

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`060_gatesv100.v`](./060_gatesv100.v).

```verilog
module top_module (
    input  [99:0] in,
    output [98:0] out_both,
    output [99:1] out_any,
    output [99:0] out_different
);
    assign out_both      = in[98:0] & in[99:1];
    assign out_any       = in[99:1] | in[98:0];
    assign out_different = in ^ {in[0], in[99:1]};
endmodule
```
