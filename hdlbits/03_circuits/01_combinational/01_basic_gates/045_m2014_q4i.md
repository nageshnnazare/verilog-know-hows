# 045. GND

**Section:** Circuits — Combinational Logic — Basic Gates  
**HDLBits:** [GND](https://hdlbits.01xz.net/wiki/Exams/m2014_q4i)

## Problem

Drive output `out` to constant 0 (ground).

## Figures (from HDLBits)

Copied from the official HDLBits problem page for this tutorial.

![Figure 1](./045_m2014_q4i_fig1.png)

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`045_m2014_q4i.v`](./045_m2014_q4i.v).

```verilog
module top_module (
    output out
);
    assign out = 1'b0;
endmodule
```
