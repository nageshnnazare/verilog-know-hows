# 053. Simple circuit A

**Section:** Circuits — Combinational Logic — Basic Gates  
**HDLBits:** [Simple circuit A](https://hdlbits.01xz.net/wiki/Mt2015_q4a)

## Problem

Circuit A from the exam figure implements
  z = (x ^ y) & x
which is the same as x & ~y.

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`053_mt2015_q4a.v`](./053_mt2015_q4a.v).

```verilog
module top_module (
    input  x,
    input  y,
    output z
);
    assign z = (x ^ y) & x;
endmodule
```
