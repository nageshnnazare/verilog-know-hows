# 052. Two-bit equality

**Section:** Circuits — Combinational Logic — Basic Gates  
**HDLBits:** [Two-bit equality](https://hdlbits.01xz.net/wiki/Mt2015_eq2)

## Problem

Output `z` is 1 iff 2-bit vectors `a` and `b` are equal.

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`052_mt2015_eq2.v`](./052_mt2015_eq2.v).

```verilog
module top_module (
    input  [1:0] a,
    input  [1:0] b,
    output       z
);
    assign z = (a == b);
endmodule
```
