# 046. NOR

**Section:** Circuits — Combinational Logic — Basic Gates  
**HDLBits:** [NOR](https://hdlbits.01xz.net/wiki/Exams/m2014_q4e)

## Problem

2-input NOR: `out = ~(in1 | in2)`.

## Figures (from HDLBits)

Copied from the official HDLBits problem page for this tutorial.

![Figure 1](./046_m2014_q4e_fig1.png)

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`046_m2014_q4e.v`](./046_m2014_q4e.v).

```verilog
module top_module (
    input  in1,
    input  in2,
    output out
);
    assign out = ~(in1 | in2);
endmodule
```
