# 047. Another gate

**Section:** Circuits — Combinational Logic — Basic Gates  
**HDLBits:** [Another gate](https://hdlbits.01xz.net/wiki/Exams/m2014_q4f)

## Problem

AND of `in1` with the inversion of `in2`: `out = in1 & ~in2`.

## Figures (from HDLBits)

Copied from the official HDLBits problem page for this tutorial.

![Figure 1](./047_m2014_q4f_fig1.png)

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`047_m2014_q4f.v`](./047_m2014_q4f.v).

```verilog
module top_module (
    input  in1,
    input  in2,
    output out
);
    assign out = in1 & ~in2;
endmodule
```
