# 077. Minimum SOP and POS

**Section:** Circuits — Combinational Logic — Karnaugh Map to Circuit  
**HDLBits:** [Minimum SOP and POS](https://hdlbits.01xz.net/wiki/Exams/ece241_2013_q2)

## Problem

A 4-input function is 1 for minterms 2, 7, 15; 0 for
0,1,4,5,6,9,10,13,14; don't-care for the rest (3,8,11,12).

Minimum SOP (cover 2,7,15 using don't-cares):
  out_sop = (c & d) | (~a & ~b & c)
Minimum POS:
  out_pos = c & (~a | ~b | d) & (~b | ~c | d)   (one accepted form)
Equivalently implement POS from the 0-maxterms.

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`077_ece241_2013_q2.v`](./077_ece241_2013_q2.v).

```verilog
module top_module (
    input  a, b, c, d,
    output out_sop,
    output out_pos
);
    assign out_sop = (c & d) | (~a & ~b & c);
    assign out_pos = c & (~b | d) & (~a | b | d);
endmodule
```
