# 061. 2-to-1 multiplexer

**Section:** Circuits — Combinational Logic — Multiplexers  
**HDLBits:** [2-to-1 multiplexer](https://hdlbits.01xz.net/wiki/Mux2to1)

## Problem

1-bit 2:1 mux. `sel=0` chooses `a`, `sel=1` chooses `b`.

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`061_mux2to1.v`](./061_mux2to1.v).

```verilog
module top_module (
    input  a, b, sel,
    output out
);
    assign out = sel ? b : a;
endmodule
```
