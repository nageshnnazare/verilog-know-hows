# 065. 256-to-1 4-bit multiplexer

**Section:** Circuits — Combinational Logic — Multiplexers  
**HDLBits:** [256-to-1 4-bit multiplexer](https://hdlbits.01xz.net/wiki/Mux256to1v)

## Problem

256:1 mux of 4-bit words packed in `in[1023:0]`.
out = in[sel*4+3 : sel*4].

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`065_mux256to1v.v`](./065_mux256to1v.v).

```verilog
module top_module (
    input  [1023:0] in,
    input  [7:0]    sel,
    output [3:0]    out
);
    assign out = in[sel*4 +: 4];
endmodule
```
