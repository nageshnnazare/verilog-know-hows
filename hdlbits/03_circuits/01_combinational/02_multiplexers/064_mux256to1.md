# 064. 256-to-1 multiplexer

**Section:** Circuits — Combinational Logic — Multiplexers  
**HDLBits:** [256-to-1 multiplexer](https://hdlbits.01xz.net/wiki/Mux256to1)

## Problem

256:1 mux of 1-bit inputs packed in `in[255:0]`, selected by `sel[7:0]`.

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`064_mux256to1.v`](./064_mux256to1.v).

```verilog
module top_module (
    input  [255:0] in,
    input  [7:0]   sel,
    output         out
);
    assign out = in[sel];
endmodule
```
