# 069. Adder

**Section:** Circuits — Combinational Logic — Arithmetic Circuits  
**HDLBits:** [Adder](https://hdlbits.01xz.net/wiki/Exams/m2014_q4j)

## Problem

Add two 4-bit numbers x and y. Output is 5-bit `sum` (includes carry out).

## Figures (from HDLBits)

Copied from the official HDLBits problem page for this tutorial.

![Figure 1](./069_m2014_q4j_fig1.png)

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`069_m2014_q4j.v`](./069_m2014_q4j.v).

```verilog
module top_module (
    input  [3:0] x,
    input  [3:0] y,
    output [4:0] sum
);
    assign sum = x + y;
endmodule
```
