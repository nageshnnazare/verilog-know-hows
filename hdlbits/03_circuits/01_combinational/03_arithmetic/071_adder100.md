# 071. 100-bit binary adder

**Section:** Circuits — Combinational Logic — Arithmetic Circuits  
**HDLBits:** [100-bit binary adder](https://hdlbits.01xz.net/wiki/Adder100)

## Problem

100-bit adder: {cout, sum} = a + b + cin.

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`071_adder100.v`](./071_adder100.v).

```verilog
module top_module (
    input  [99:0] a, b,
    input         cin,
    output        cout,
    output [99:0] sum
);
    assign {cout, sum} = a + b + cin;
endmodule
```
