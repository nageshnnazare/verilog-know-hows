# 070. Signed addition overflow

**Section:** Circuits — Combinational Logic — Arithmetic Circuits  
**HDLBits:** [Signed addition overflow](https://hdlbits.01xz.net/wiki/Exams/ece241_2014_q1c)

## Problem

8-bit signed adder: s = a + b. Overflow is 1 when the two operands
have the same sign and the result has the opposite sign:
  overflow = a[7]&b[7]&~s[7] | ~a[7]&~b[7]&s[7]

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`070_ece241_2014_q1c.v`](./070_ece241_2014_q1c.v).

```verilog
module top_module (
    input  [7:0] a,
    input  [7:0] b,
    output [7:0] s,
    output       overflow
);
    assign s = a + b;
    assign overflow = (a[7] & b[7] & ~s[7]) | (~a[7] & ~b[7] & s[7]);
endmodule
```
