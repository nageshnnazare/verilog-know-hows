# 116. Rule 90

**Section:** Circuits — Sequential Logic — More Circuits  
**HDLBits:** [Rule 90](https://hdlbits.01xz.net/wiki/Rule90)

## Problem

512-cell elementary cellular automaton, Rule 90: next[i] = left XOR right.
`load` parallel-loads `data`. Neighbours past the ends are 0.
Advance one generation each clock when not loading.

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`116_rule90.v`](./116_rule90.v).

```verilog
module top_module (
    input             clk,
    input             load,
    input      [511:0] data,
    output reg [511:0] q
);
    always @(posedge clk) begin
        if (load)
            q <= data;
        else
            q <= {1'b0, q[511:1]} ^ {q[510:0], 1'b0};
    end
endmodule
```
