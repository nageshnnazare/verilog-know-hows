# 083. DFF with reset

**Section:** Circuits — Sequential Logic — Latches and Flip-Flops  
**HDLBits:** [DFF with reset](https://hdlbits.01xz.net/wiki/Dff8r)

## Problem

8-bit register with active-high synchronous reset to 0.

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`083_dff8r.v`](./083_dff8r.v).

```verilog
module top_module (
    input            clk,
    input            reset,
    input      [7:0] d,
    output reg [7:0] q
);
    always @(posedge clk) begin
        if (reset)
            q <= 8'd0;
        else
            q <= d;
    end
endmodule
```
