# 092. Mux and DFF

**Section:** Circuits — Sequential Logic — Latches and Flip-Flops  
**HDLBits:** [Mux and DFF](https://hdlbits.01xz.net/wiki/Exams/2014_q4a)

## Problem

One cell of a shift register: a DFF whose next value is
  L=1: load R
  L=0, E=1: shift in w
  L=0, E=0: hold q

Copied from the official HDLBits problem page for this tutorial.

![Figure 1](./092_2014_q4a_fig1.png)

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`092_2014_q4a.v`](./092_2014_q4a.v).

```verilog
module top_module (
    input      clk,
    input      w, R, E, L,
    output reg Q
);
    always @(posedge clk) begin
        if (L)
            Q <= R;
        else if (E)
            Q <= w;
    end
endmodule
```
