# 090. DFF+gate

**Section:** Circuits — Sequential Logic — Latches and Flip-Flops  
**HDLBits:** [DFF+gate](https://hdlbits.01xz.net/wiki/Exams/m2014_q4d)

## Problem

XOR the input with the current output and register that on posedge
clk (a toggle-when-in-is-1 / XOR-feedback DFF):
  q <= q ^ in
Output is q. Reset is not present on this figure.

## Figures (from HDLBits)

Copied from the official HDLBits problem page for this tutorial.

![Figure 1](./090_m2014_q4d_fig1.png)

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`090_m2014_q4d.v`](./090_m2014_q4d.v).

```verilog
module top_module (
    input      clk,
    input      in,
    output reg out
);
    always @(posedge clk)
        out <= out ^ in;
endmodule
```
