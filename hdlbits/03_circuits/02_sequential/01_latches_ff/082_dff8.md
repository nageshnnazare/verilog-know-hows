# 082. D flip-flops

**Section:** Circuits — Sequential Logic — Latches and Flip-Flops  
**HDLBits:** [D flip-flops](https://hdlbits.01xz.net/wiki/Dff8)

## Problem

8-bit register: q[7:0] <= d[7:0] on posedge clk.

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`082_dff8.v`](./082_dff8.v).

```verilog
module top_module (
    input            clk,
    input      [7:0] d,
    output reg [7:0] q
);
    always @(posedge clk)
        q <= d;
endmodule
```
