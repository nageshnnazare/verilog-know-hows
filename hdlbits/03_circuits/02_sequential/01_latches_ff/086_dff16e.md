# 086. DFF with byte enable

**Section:** Circuits — Sequential Logic — Latches and Flip-Flops  
**HDLBits:** [DFF with byte enable](https://hdlbits.01xz.net/wiki/Dff16e)

## Problem

16-bit register, synchronous reset to 0. Byte enables:
  byteena[1] enables q[15:8], byteena[0] enables q[7:0].
Unenabled bytes hold their value.

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`086_dff16e.v`](./086_dff16e.v).

```verilog
module top_module (
    input            clk,
    input            resetn,
    input      [1:0] byteena,
    input      [15:0] d,
    output reg [15:0] q
);
    always @(posedge clk) begin
        if (!resetn)
            q <= 16'd0;
        else begin
            if (byteena[1]) q[15:8] <= d[15:8];
            if (byteena[0]) q[7:0]  <= d[7:0];
        end
    end
endmodule
```
