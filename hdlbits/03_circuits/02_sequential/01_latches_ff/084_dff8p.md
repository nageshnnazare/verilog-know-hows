# 084. DFF with reset value

**Section:** Circuits — Sequential Logic — Latches and Flip-Flops  
**HDLBits:** [DFF with reset value](https://hdlbits.01xz.net/wiki/Dff8p)

## Problem

8-bit register clocked on the *negative* edge, with active-high
synchronous reset that loads 8'h34.

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`084_dff8p.v`](./084_dff8p.v).

```verilog
module top_module (
    input            clk,
    input            reset,
    input      [7:0] d,
    output reg [7:0] q
);
    always @(negedge clk) begin
        if (reset)
            q <= 8'h34;
        else
            q <= d;
    end
endmodule
```
