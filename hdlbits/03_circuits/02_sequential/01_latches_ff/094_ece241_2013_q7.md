# 094. Create circuit from truth table

**Section:** Circuits — Sequential Logic — Latches and Flip-Flops  
**HDLBits:** [Create circuit from truth table](https://hdlbits.01xz.net/wiki/Exams/ece241_2013_q7)

## Problem

Implement a JK flip-flop from a DFF using the characteristic table:
  J K | Q+
  0 0 | Q
  0 1 | 0
  1 0 | 1
  1 1 | ~Q

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`094_ece241_2013_q7.v`](./094_ece241_2013_q7.v).

```verilog
module top_module (
    input      clk,
    input      j,
    input      k,
    output reg Q
);
    always @(posedge clk) begin
        case ({j, k})
            2'b00: Q <= Q;
            2'b01: Q <= 1'b0;
            2'b10: Q <= 1'b1;
            2'b11: Q <= ~Q;
        endcase
    end
endmodule
```
