# 109. Left/right arithmetic shift by 1 or 8

**Section:** Circuits — Sequential Logic — Shift Registers  
**HDLBits:** [Left/right arithmetic shift by 1 or 8](https://hdlbits.01xz.net/wiki/Shift18)

## Problem

64-bit arithmetic shifter. `load` loads `data`. When `ena`:
  amount=00: shift left 1
  amount=01: shift left 8
  amount=10: arithmetic shift right 1
  amount=11: arithmetic shift right 8

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`109_shift18.v`](./109_shift18.v).

```verilog
module top_module (
    input             clk,
    input             load,
    input             ena,
    input      [1:0]  amount,
    input      [63:0] data,
    output reg [63:0] q
);
    always @(posedge clk) begin
        if (load)
            q <= data;
        else if (ena) begin
            case (amount)
                2'b00: q <= q << 1;
                2'b01: q <= q << 8;
                2'b10: q <= {q[63], q[63:1]};
                2'b11: q <= {{8{q[63]}}, q[63:8]};
            endcase
        end
    end
endmodule
```
