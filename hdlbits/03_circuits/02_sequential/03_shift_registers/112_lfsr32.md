# 112. 32-bit LFSR

**Section:** Circuits — Sequential Logic — Shift Registers  
**HDLBits:** [32-bit LFSR](https://hdlbits.01xz.net/wiki/Lfsr32)

## Problem

32-bit Galois LFSR with taps at 32, 22, 2, 1. Synchronous reset to 1.
Fibonacci form: q <= {q[30:0], q[31]^q[21]^q[1]^q[0]}.

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`112_lfsr32.v`](./112_lfsr32.v).

```verilog
module top_module (
    input             clk,
    input             reset,
    output reg [31:0] q
);
    always @(posedge clk) begin
        if (reset)
            q <= 32'h1;
        else
            q <= {q[30:0], q[31] ^ q[21] ^ q[1] ^ q[0]};
    end
endmodule
```
