# 108. Left/right rotator

**Section:** Circuits — Sequential Logic — Shift Registers  
**HDLBits:** [Left/right rotator](https://hdlbits.01xz.net/wiki/Rotate100)

## Problem

100-bit rotator. `load` parallel-loads `data`. Otherwise `ena`:
  2'b01: rotate right by 1
  2'b10: rotate left by 1
  other: hold

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`108_rotate100.v`](./108_rotate100.v).

```verilog
module top_module (
    input             clk,
    input             load,
    input      [1:0]  ena,
    input      [99:0] data,
    output reg [99:0] q
);
    always @(posedge clk) begin
        if (load)
            q <= data;
        else begin
            case (ena)
                2'b01: q <= {q[0], q[99:1]};
                2'b10: q <= {q[98:0], q[99]};
                default: q <= q;
            endcase
        end
    end
endmodule
```
