# 144. Q3c: FSM logic

**Section:** Circuits — Sequential Logic — Finite State Machines  
**HDLBits:** [Q3c: FSM logic](https://hdlbits.01xz.net/wiki/Exams/2014_q3c)

## Problem

Combinational next-state for the Q3 FSM given Y2,Y1,Y0 and x.
Output Y2A,Y1A,Y0A (next bits) and z.
Equations from the exam state table (one accepted set):
  Y2A = (~Y2 & Y1 & ~Y0 & x) | (Y2 & ~Y1 & ~Y0)
  ... use a compact case on {Y2,Y1,Y0,x}.

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`144_2014_q3c.v`](./144_2014_q3c.v).

```verilog
module top_module (
    input  [3:1] y,
    input        w,
    output       Y2
);
    // Official ports are y[3:1], w, Y2 — only next-state bit Y2.
    assign Y2 = (y == 3'b001 && w == 1'b0)
              | (y == 3'b010 && w == 1'b0)
              | (y == 3'b101 && w == 1'b0)
              | (y == 3'b110 && w == 1'b0);
endmodule
```
