# 146. Q6c: FSM one-hot next-state logic

**Section:** Circuits — Sequential Logic — Finite State Machines  
**HDLBits:** [Q6c: FSM one-hot next-state logic](https://hdlbits.01xz.net/wiki/Exams/m2014_q6c)

## Problem

One-hot version. States y[6:1], input w. Produce Y2 and Y4.
Equations from the one-hot diagram:
  Y2 = y[1] & ~w
  Y4 = (y[2] | y[3] | y[5] | y[6]) & w   (example — see official figure)
A widely used pair:
  Y2 = y[1] & ~w
  Y4 = y[2] & w | y[3] & w | y[5] & w | y[6] & w

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`146_m2014_q6c.v`](./146_m2014_q6c.v).

```verilog
module top_module (
    input  [6:1] y,
    input        w,
    output       Y2,
    output       Y4
);
    assign Y2 = y[1] & ~w;
    assign Y4 = (y[2] | y[3] | y[5] | y[6]) & w;
endmodule
```
