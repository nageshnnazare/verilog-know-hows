# 139. Q8: Design a Mealy FSM

**Section:** Circuits — Sequential Logic — Finite State Machines  
**HDLBits:** [Q8: Design a Mealy FSM](https://hdlbits.01xz.net/wiki/Exams/ece241_2013_q8)

## Problem

Mealy FSM that detects overlapping sequence 101. Asynchronous reset.
`z` is 1 in the cycle when the third bit of 101 arrives.

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`139_ece241_2013_q8.v`](./139_ece241_2013_q8.v).

```verilog
module top_module (
    input      clk,
    input      aresetn,
    input      x,
    output     z
);
    parameter S0=0, S1=1, S2=2;
    reg [1:0] state, next;
    always @(*) begin
        case (state)
            S0: next = x ? S1 : S0;
            S1: next = x ? S1 : S2;
            S2: next = x ? S1 : S0;
            default: next = S0;
        endcase
    end
    always @(posedge clk or negedge aresetn) begin
        if (!aresetn)
            state <= S0;
        else
            state <= next;
    end
    assign z = (state == S2) && x;
endmodule
```
