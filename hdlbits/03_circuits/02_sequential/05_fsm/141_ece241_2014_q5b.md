## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`141_ece241_2014_q5b.v`](./141_ece241_2014_q5b.v).

```verilog
module top_module (
    input      clk,
    input      areset,
    input      x,
    output     z
);
    parameter A=0, B=1;
    reg state;
    always @(posedge clk or posedge areset) begin
        if (areset)
            state <= A;
        else if (state == A && x)
            state <= B;
    end
    assign z = (state == A) ? x : ~x;
endmodule
```
