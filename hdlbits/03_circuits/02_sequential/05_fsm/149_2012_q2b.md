# 149. Q2b: One-hot FSM equations

**Section:** Circuits — Sequential Logic — Finite State Machines  
**HDLBits:** [Q2b: One-hot FSM equations](https://hdlbits.01xz.net/wiki/Exams/2012_q2b)

## Problem

One-hot next-state bits y[3:1] / Y1,Y3 for the 2012 FSM.
Ports: y[3:1], w, Y1, Y3.

## Figures (from HDLBits)

Copied from the official HDLBits problem page for this tutorial.

![Figure 1](./149_2012_q2b_fig1.png)

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`149_2012_q2b.v`](./149_2012_q2b.v).

```verilog
module top_module (
    input  [3:1] y,
    input        w,
    output       Y1,
    output       Y3
);
    assign Y1 = y[2] & ~w;
    assign Y3 = (y[1] | y[2] | y[3]) & w;
endmodule
```
