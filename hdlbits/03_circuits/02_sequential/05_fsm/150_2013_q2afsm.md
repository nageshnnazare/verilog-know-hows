# 150. Q2a: FSM

**Section:** Circuits — Sequential Logic — Finite State Machines

## Problem

2013 Q2a FSM. Asynchronous reset. Input w, output z.
States A-F with a different diagram from 2012.
Common diagram:
  A -0-> A, A -1-> B
  B -0-> C, B -1-> D
  ...

## Solution

The module is named `top_module` so you can paste it into HDLBits. The same source is in [`150_2013_q2afsm.v`](./150_2013_q2afsm.v).

```verilog
module top_module (
    input      clk,
    input      resetn,
    input      w,
    output     z
);
    parameter A=0, B=1, C=2, D=3, E=4, F=5;
    reg [2:0] state, next;
    always @(*) begin
        case (state)
            A: next = w ? B : A;
            B: next = w ? C : D;
            C: next = w ? E : D;
            D: next = w ? F : A;
            E: next = w ? E : D;
            F: next = w ? C : D;
            default: next = A;
        endcase
    end
    always @(posedge clk) begin
        if (!resetn)
            state <= A;
        else
            state <= next;
    end
    assign z = (state == E) || (state == F);
endmodule
```
